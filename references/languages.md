# Listing languages

One listing per language **actually available in the app**: a Spanish listing for a French-only app misleads users (and can get the app rejected). If the user wants a language the app does not have yet, say so and suggest translating the app first, or preparing the listing without publishing it.

## Language codes

| Language | App Store Connect | Play Console | Notes |
| --- | --- | --- | --- |
| French | French (fr-FR) | French – fr-FR | A separate fr-CA listing only if the texts differ for Quebec. |
| English | English (U.S.) (en-US) | English (United States) – en-US | en-GB, en-AU… inherit from en-US if left empty (Apple and Google show the closest language). |
| Spanish (Latin America) | Spanish (Mexico) (es-MX) | Spanish (Latin America) – es-419 | Apple has no "es-419": es-MX is shown across Latin America. |
| Spanish (Spain) | Spanish (Spain) (es-ES) | Spanish (Spain) – es-ES | |
| Portuguese (Brazil) | Portuguese (Brazil) (pt-BR) | Portuguese (Brazil) – pt-BR | |
| Portuguese (Portugal) | Portuguese (Portugal) (pt-PT) | Portuguese (Portugal) – pt-PT | |
| German | German (de-DE) | German – de-DE | Longer texts: check the limits. |
| Italian | Italian (it) | Italian – it-IT | |
| Dutch | Dutch (nl-NL) | Dutch – nl-NL | |
| Japanese | Japanese (ja) | Japanese – ja-JP | Apple keywords: no commas needed between Japanese words, but the limit is still 100. |
| Arabic, Hebrew | ar-SA, he | ar, iw-IL | Right-to-left languages: check the screenshots. |

Primary language: the one the stores show when no listing matches the phone's language. Usually English for an international app; the source language for a single-country app.

## Writing in another language

- **Adapt** hooks, puns and examples (a funny example in French is not necessarily funny in English).
- **Keywords**: redo the research for each language (people do not search for the literal translation). Example: "patate chaude" / "hot potato" / "papa caliente" (Latin America) / "patata caliente" (Spain) / "batata quente" / "heiße Kartoffel" / "patata bollente".
- **Variants**: es-419 ("celular", "papa") or es-ES ("móvil", "patata"); pt-BR ("celular", "você") or pt-PT ("telemóvel", "tu").
- **Register**: keep the app's register (informal or formal "you": "tu" or "vous", "tú" or "usted").
- **Typography**: « » quotes in French, “ ” in English, « » in Spanish, „ “ in German; space before "? ! : ;" in French only.
- **Review notes**: always in English, whatever the language of the listings.
- **Screenshots**: one set per language, with the app displayed in that language (set the phone or the app to that language before capturing).
